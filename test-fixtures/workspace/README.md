# Save as Zip Test Workspace

Use this folder with `npm run web`.

Suggested manual checks:

1. Right-click `single-file.txt` and run `Save as Zip`.
2. Select `multi-one.txt`, `multi-two.txt`, and `folder-to-zip`, then right-click one selected item and run `Save as Zip`.
3. Right-click `folder-to-zip` and run `Save as Zip`.

Expected download names:

- `single-file.zip`
- `selected-files.zip`
- `folder-to-zip.zip`
